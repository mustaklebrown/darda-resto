# Guide de Soumission Google - Darda Resto

## 🎯 Actions Prioritaires pour Améliorer le Référencement

### 1. Google Search Console (URGENT - À faire maintenant)

#### Étape 1: Créer un compte

1. Allez sur https://search.google.com/search-console
2. Connectez-vous avec un compte Google
3. Cliquez sur "Ajouter une propriété"
4. Entrez: `https://darda-resto-3eiv.vercel.app`

#### Étape 2: Vérifier la propriété

Choisissez une méthode de vérification:

- **Méthode recommandée**: Balise HTML meta
- Ajoutez la balise dans `app/layout.tsx`
- Ou utilisez la vérification DNS si vous avez accès au domaine

#### Étape 3: Soumettre le sitemap

1. Dans Search Console, allez dans "Sitemaps"
2. Ajoutez: `https://darda-resto-3eiv.vercel.app/sitemap.xml`
3. Cliquez sur "Soumettre"
